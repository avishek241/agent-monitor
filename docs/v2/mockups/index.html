Agent Deck · three UI versions

Each version covers the same content: the all-projects overview and per-project pages, accounts (with the office account shown for usage only and greyed out with its reason), workers with parallel lanes, quota and time to reset, the board with dependencies, the review inbox, the timeline, alerts and repo health. Each has a phone deck (390 px PWA) and a compact floating panel. All data is made up.
